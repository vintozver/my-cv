# Winds and temperatures aloft display for Skydive Toledo

A dedicated display pulls updates from trusted weather sources and presents current
conditions to jumpers.

![Skydive Toledo winds and temperatures aloft display](https://manifest.skydivetoledo.com/wt-aloft/local)

Implemented on a Raspberry Pi Zero 2 W.

**Technologies:** Raspberry Pi, GitHub Copilot, AI, and Python 3.

[Open the local winds and temperatures aloft display](https://manifest.skydivetoledo.com/wt-aloft/local)
